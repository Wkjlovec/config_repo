# iTerm2

iTerm2 的完整偏好设置含有机器路径，先不自动链接。

建议手动设置：

- Profiles -> Default -> Command: Login shell。
- Profiles -> Default -> Working Directory: Reuse previous session's directory。
- Keys: 保持 macOS 默认，避免和 Karabiner/Hammerspoon 冲突。
- Font: JetBrains Mono 或系统等宽字体。

如果后续想同步 iTerm2 设置：

1. iTerm2 -> Settings -> General -> Preferences。
2. 勾选 `Load preferences from a custom folder or URL`。
3. 选择这个目录。
